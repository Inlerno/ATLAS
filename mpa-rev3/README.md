## 4. Термины

| Термин | Определение |
|---|---|
| Remote Access | core-сервис Desktop, принимающий запросы сопряжённых устройств; сетевой listener выключен по умолчанию |
| Remote API | версионированный API Remote Access (`/api/v1`) поверх TLS 1.3: REST + WebSocket |
| Event Gateway | часть Remote Access: подписчик единственной шины событий, доставляющий разрешённые события устройствам |
| Connection Manager | часть Remote Access: учёт соединений устройств, закрытие при отзыве |
| Request Journal | журнал удалённых запросов с побочными эффектами в SQLite Desktop |
| Remote Client | сетевой клиент в Rust-ядре мобильного приложения (TLS, pinning, аутентификация, локальный журнал) |
| Intent | каноническое описание запрошенного действия (без транспортных данных и подтверждений) |
| `intent_hash` | SHA-256 канонической формы Intent |
| Confirmation evidence | подпись подтверждения (биометрия на телефоне) или решение пользователя на Desktop; хранится отдельно от Intent |
| `grant_version` | монотонная версия прав устройства в реестре |
| `outcome_unknown` | конечное состояние: действие могло быть выполнено, но это не подтверждено |
| Сверка при старте (sweep) | перевод незавершённых записей журнала при запуске Desktop |
| Desktop key | ключ TLS-сервера Desktop; его SPKI-хэш закрепляется телефоном (pin) |
| Ключи устройства | `device_session_key` (аутентификация соединений) и `device_confirmation_key` (подтверждения, только после биометрии) |
